# 📋 Thư Mục Chứa File Yêu Cầu (Requirements)

Đây là nơi thả các file ghi chú yêu cầu, danh sách tính năng, hoặc tài liệu chức năng được xuất từ **Google NotebookLM**.

### 📝 Định dạng hỗ trợ:
- `.md` (Markdown - Khuyên dùng)
- `.txt` (Text đơn thuần)
- `.json` (Dữ liệu cấu trúc)
