# 🎨 Thư Mục Chứa File Thiết Kế (Designs & UI Blueprints)

Đây là nơi thả các file mô tả thiết kế giao diện UI/UX, bản thiết kế sơ đồ (Blueprint), mockup hoặc hình ảnh thiết kế từ **Google NotebookLM** hoặc Figma/dự án.

### 🖼️ Định dạng hỗ trợ:
- `.md` (File mô tả giao diện / UI Specification - Khuyên dùng)
- `.png`, `.jpg`, `.svg` (Ảnh thiết kế giao diện)
- `.json` (UI tokens, layout config)

---
*Gợi ý: Thả file `mobile-task-ui-blueprint.md` hoặc ảnh thiết kế vào đây và nhắn AI "Thiết kế giao diện theo file trong thư mục designs".*
